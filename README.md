# Movie-Finder
This program reads a list of movies from the file and puts it into an array that is sorted by title and lets the person using for a movie title

How to run it
1. Check that Movies.txt contains the movie list that is expected in the .zip file
2. check the filename in the main.cpp if it matches the .txt file
3. Once uploading the file to either an online compiler or Vs code (I use online GDB)
4. Afterwards, check the output. The list should appear with the titles in order, and the search should report whether it found the title. If it fails, It should be easy to fix as any compiler should tell you where it messed up

What I learned
I learned how to read structured data from a file into an array of structs, sort the records by movie title, and search the array for a title entered by the user. I also practiced breaking a program into functions and checking that the input filename and data format match what the code expects.
